**Course outline**
- This course consists of three modules.

## Module 1: Getting Started with MCP
- Lesson 0: Welcome
- Lesson 1: Introduction to MCP
- Lesson 2: MCP in Action
- Lesson 3: Module Summary, Cheat Sheet, and Evaluation

### Key topics:
- Model Context Protocol (MCP) fundamentals
- MCP client–server architecture
- Building and running basic MCP applications in Python


## Module 2: MCP Server
- Lesson 1: MCP Server Basics
- Lesson 2: Building Enhanced MCP Servers
- Lesson 3: Module Summary, Cheat Sheet, and Evaluation

### Key topics:
- Converting tools into MCP servers
- Extending servers with resources and prompts
- Running and testing MCP servers


## Module 3: MCP Hosts and Clients

- Lesson 1: MCP Client Implementation Patterns
- Lesson 2: Advanced MCP Features: Sampling and Roots
- Lesson 3: User Interaction Patterns: Elicitation and Permissions
- Lesson 4: Module Summary, Cheat Sheet, and Evaluation
- Lesson 5: Course Wrap-Up

### Key topics:
- Query routing and retrieval
- MCP client architecture and lifecycle management
- Connection pooling, caching, and load balancing
- Advanced features: sampling, root controls, and bidirectional LLM calls
- Secure user interaction and permissions

## Tools/software
- In this course, you will explore and utilize a variety of tools and platforms, including:
- Python: For building and running MCP clients and servers, scripting workflows, and implementing multi-agent applications.
- MCP Servers and Clients: Provided labs and environments to develop, test, and run MCP applications.
- Cloud IDE: To run hands-on labs for building and testing MCP clients and servers.
- HTTP and Standard I/O tools: For managing client-server communication
